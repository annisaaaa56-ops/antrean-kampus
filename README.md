# Layanan Antrean Kampus

Layanan Antrean Kampus adalah aplikasi web untuk mengelola antrean layanan kampus secara tertib dan transparan. Mahasiswa dapat mengambil nomor antrean secara online, melihat posisi antrean, dan mendapatkan perkiraan waktu tunggu tanpa harus mengantre secara fisik.

## Petunjuk Menjalankan

1. Clone repository ini
2. Masuk ke folder proyek
3. Jalankan perintah untuk memulai aplikasi
4. Buka browser dan akses aplikasi

> Catatan: Petunjuk menjalankan yang detail akan dilengkapi setelah aplikasi selesai dibuat.

## Aturan Kerja Tim

1. Setiap anggota wajib melakukan pull sebelum mulai mengerjakan tugas.
2. Setiap perubahan dikerjakan di branch masing-masing, tidak langsung di main.
3. Setiap perubahan harus di-commit dengan pesan yang jelas.
4. Setiap anggota wajib melakukan pull request dan menunggu review dari ketua sebelum merge.
5. Dilarang menghapus file milik anggota lain tanpa diskusi terlebih dahulu.
6. Semua komunikasi dan pembagian tugas dilakukan melalui grup tim.
